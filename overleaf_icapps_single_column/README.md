# ICAPPS/IEEE single-column concept and progress draft

This folder contains the revised paper concept followed by a dataset-progress
and experiment-to-paper roadmap section, in a single-column version of the
supplied ICAPPS conference format. `main.tex` uses
`\documentclass[conference,onecolumn]{IEEEtran}` and retains the IEEE title
block, typography, abstract, keywords, numbered sections, tables, and numbered
references without the double-column layout.

The official ICAPPS submission format may still require two columns. For final
submission, remove `onecolumn` from the document-class options if required by
the conference instructions.

## Upload to Overleaf

1. Upload `overleaf_icapps_single_column.zip` as a new Overleaf project, or upload
   `main.tex` into a blank project.
2. Ensure `main.tex` is selected as the main document.
3. Replace the placeholder author names, affiliations, city/country, and email
   or ORCID fields.
4. Add a `\thanks{...}` entry only if a funding acknowledgment is required.

No external bibliography or figure files are required for this draft.
