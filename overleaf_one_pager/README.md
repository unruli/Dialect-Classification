# Two-page paper concept and progress roadmap

This folder contains a compact two-page external-review document. Page 1 is the
paper concept; Page 2 records dataset progress, remaining experiments,
analysis, artifacts, and completion gates. It uses a single-page-width layout
with two internal text columns so each section remains readable.

## Upload to Overleaf

1. Upload the folder as a new Overleaf project, or upload
   `main.tex` into a blank project.
2. Ensure `main.tex` is selected as the main document.
3. Compile with pdfLaTeX. No external bibliography or figure files are needed.
